# LZtimer — IndexedDB 完整版

## 本地运行 / 公共发布

本包包含全部网页源码，无构建步骤、无后端 API 密钥。解压后在文件夹运行：

    python3 -m http.server 8765

访问 http://localhost:8765/ ，比赛页 competition.html。不要直接双击 HTML。公共部署时上传全部文件到静态托管服务；建议启用 HTTPS。若需要 /competition 路径，可映射到 /competition.html。外部图表、图标及 cubing 打乱/预览依赖通过 CDN 加载，需要联网。

## 新存储引擎

storage.js 使用 LZTimerDB v1。solves 表主键 id，索引 event、timestamp。每条成绩仅存 id/event/time/penalty/scramble/timestamp 六个字段，无计算后的平均值。membership 表单独记录分组关联与稳定的录入顺序；meta 表保存轻量分组/选择状态；rounds 表保存比赛轮次信息和每轮最多五条成绩的 ID。

新增、修改和删除只写一条成绩；分组清空使用索引游标，只删除目标分组。若分组包含数据库全部成绩，则直接 clear。批量导入每 500 条一个事务，读取每 1,000 条分批执行。练习和比赛成绩相互隔离。

首次使用本版本会清除旧 lztimer-v1 和 lztimer-competition-v1 中的测试成绩。旧分组名称、主题、分析选项尽量保留，语言和输入设置保留。后续启动不会清除 IndexedDB 中的新成绩。

## 关闭浏览器后保存

每条成绩在 IndexedDB 事务完成后才标记 Saved。写入尚未结束时离开页面会触发浏览器离开提醒（是否展示由浏览器决定）。正常关闭页面或浏览器后，在相同浏览器配置、相同域名下再次打开，可恢复历史。初始化会调用 navigator.storage.persist() 申请持久化，浏览器可能拒绝。

IndexedDB 避开了 localStorage 的约 5MB 限制，但不是无限磁盘；仍受浏览器磁盘配额、可用空间及隐私模式策略限制。手动清除网站数据、删除浏览器配置或更换域名会影响记录。建议定期导出 CSV/JSON 备份；没有云同步。无痕模式不适合长期保存。

## 性能

performance-core.js 在内存缓存平均值。新增只计算最新窗口（最多 100 条）；历史修改/删除只重算受影响窗口。大历史初次建立缓存分块执行。历史表最多挂载 50 行，虚拟滚动；新增在顶部插入单行。分析图表仅弹窗打开时绘制，超过 500 条下采样到 500 点，统计/排名/导出使用全量数据。计时循环仅厘秒改变时更新缓存 DOM 引用。

## 验证

真实浏览器：写入 100,000 条，新增到 100,001 条，关闭页面后重新打开恢复全部记录；修改 +2 并刷新后保留，历史 DOM 保持 50 行。

自动化：紧凑字段、索引、旧数据清理、设置保留、100,000 条读写、单记录修改/删除、分组隔离清空、比赛恢复、平均算法对照、触控和导出回归。

文件包不含个人数据、访问凭据、Sites 项目标识或测试依赖。
